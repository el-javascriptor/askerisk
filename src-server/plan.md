# The Plan
**Summary**: This project is for the purposes of having a quick, efficient, relatively-intelligent desktop agent: Askerisk.

**Interface**: Askerisk lives in a small notch in the bottom-right of the screen. Hovering over it with one's mouse opens up a small chat interface. It is a clean, rounded, interface, with a cool asterisk logo.

**Functionality**: Askerisk can execute commands, think, and reply. It operates off of a Python backend, complete with an Electron Typescript React frontend.
